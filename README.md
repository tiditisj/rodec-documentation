# Rodec documentation

Source of [documentation.rodec.com](https://documentation.rodec.com): user
manuals, connections, data and dimensions for Rodec mixing consoles (MX
Modular, Rodec ONE) and 100 and 500 series modules.

The site is static HTML, generated by a small Python script and published
with GitHub Pages on every push to `main`.

## Build and preview

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python tools/build.py
python3 -m http.server 8000 --directory docs
```

Then open http://127.0.0.1:8000/documentation-home. `docs/` is build output
and is not committed.

## How it is organised

| Path | What |
| --- | --- |
| `content/<path>/index.html` | Page text as clean HTML, one file per page, at the same path as on the site. |
| `src/content/<path>/index.html` | Pages converted from other sources (used instead of `content/`). |
| `src/annotations/*.json` | Pages with a panel image and a numbered legend; see `src/annotations/README.md`. |
| `src/pages/` | Hand-made pages and page-specific CSS and JavaScript; `fragments/` holds reusable HTML blocks. |
| `src/rodec-docs.css` | The site stylesheet (Rodec house style). |
| `src/fonts/` | IBM Plex Sans and Mono (SIL Open Font License). |
| `src/img/` | Logo, renders, panel images and other pictures used by the site. |
| `assets/` | Images, files (PDF, CSV) and embed code referenced by the pages. |
| `site.json` | Navigation tree and page metadata. |
| `raw/` | Archived HTML of the previous version of the site, kept for reference. |
| `tools/` | Build, conversion and image tools (see the docstring at the top of each). |

Every page keeps its original URL, so links from product pages and printed
manuals keep working.

## Tools

- `tools/build.py`: builds the site into `docs/`.
- `tools/scrape.py`: re-imports pages from the previous site into `raw/`,
  `content/` and `assets/`.
- `tools/convert_gdoc.py`: turns a public Google Doc into a page in
  `src/content/`.
- `tools/preview_annotation.py`, `tools/grid_image.py`: check an annotation
  file and pick coordinates on an image.
- `tools/cutout_white.py`: cuts a product photo on a white background loose.

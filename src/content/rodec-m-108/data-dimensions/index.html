M-108 Data & dimensions

Audio performance

Default test conditions (unless otherwise stated):

  • Reference frequency: 1 kHz
  • Reference level: 0 dBu, where 0 dBu = 0.775 V into any load
  • All unweighted measurements are specified as 22 Hz to 22 kHz band limited RMS and are expressed in units of dBu
  • The onset of clipping (for headroom measurements) is taken as 1 % THD+N
  • Gain control at the unity mark, output level fully up
  • Measured with the M-108 fitted in a Rodec ONE, over the ONE's USB audio path at 48 kHz (0 dBFS = +20 dBu). The contribution of the Rodec ONE itself has been measured separately and subtracted.

Unless otherwise quoted all figures are typical values, measured on a production unit; where the two channels differ, the worse channel is given.

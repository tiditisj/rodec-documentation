Audio performance

Default test conditions (unless otherwise stated):

  • Reference frequency: 1 kHz
  • Reference level: 0 dBu, where 0 dBu = 0.775 V into any load
  • Alignment level: 0 dBFS = +20 dBu
  • Sample rate: 48 kHz
  • All unweighted measurements are specified as 22 Hz to 22 kHz band limited RMS and are expressed in units of dBu
  • The onset of clipping (for headroom measurements) is taken as 1 % THD+N
  • All controls set flat, out or at unity gain as appropriate; all other channels muted

Unless otherwise quoted all figures are typical values, measured on a production unit.

The -1.0 dB gain is by design: the USB return is summed with the analogue input in the mixer, and the summing stage takes 1 dB off.

The analogue stages do not clip before the converters reach full scale, so maximum level and dynamic range are set by 0 dBFS.

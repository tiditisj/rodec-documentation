FX Module

The MX Modular is equipped with a Dual Digital FX Module, delivering powerful and intuitive built-in effects designed for creative versatility. Featuring Rodec-engineered algorithms, this module seamlessly integrates with the console’s workflow while offering advanced customization and storage options.

Key Features of the FX Module

  1. Dual FX Engines:
    • The module provides two independent effects processors, with delay and reverb algorithms that have been meticulously crafted by Rodec.
    • These engines are pre-routed to AUX 1 and AUX 2, simplifying integration and signal flow.
  2. Advanced Parameter Control:
    • Each effect can be fine-tuned using 6 to 9 rotary knobs, offering precise control over key parameters such as time, feedback, mix, damping, and more.
    • This allows you to shape each effect to suit your specific artistic or performance needs.
  3. Customizable Presets:
    • Each FX engine supports up to 99 user-configurable preset banks, enabling you to save and recall your favorite settings effortlessly.
    • This is ideal for switching between effect setups during live performances or studio sessions.
  4. Analog AUX Integration:
    • While the built-in FX module provides extensive functionality, the MX Modular retains the flexibility to integrate external FX units.
    • By using the analog AUX send and return sockets, you can incorporate your preferred external effects alongside the built-in digital FX.

Workflow and Integration

  • Internal and External FX Blending: The system allows you to combine the internal FX with external units for layered and textured effects.
  • Seamless AUX Routing: With the FX engines pre-mapped to AUX 1 and AUX 2, routing signals to the FX module is straightforward, leaving you free to focus on fine-tuning and performance.

Summary

The Dual Digital FX Module in the MX Modular combines high-quality delay and reverb algorithms with deep customization and the ability to store up to 99 presets. Its intuitive design integrates seamlessly with AUX 1 and AUX 2, while retaining the freedom to connect external FX units via analog AUX sends and returns. Whether in the studio or on stage, this module provides a versatile and creative effects solution.

Loading and Saving a Preset

The MX Modular FX Module provides a straightforward and intuitive process for loading and saving presets, allowing you to manage your effects with ease.

Loading a Preset

  1. Dial to Select:
    • Use the rotary knob next to the LED to scroll through available presets.
    • The selected preset will load automatically when you stop turning the knob.
    • Factory presets are in bank 1 from 01 to 20
    • User presets are bank 2 from 0.1. to 9.9.
    • Bank 2 follows as soon as you have reached the end of bank 1

Saving a Preset

  1. Initiate Save:
    • Press and hold the rotary knob for 3 seconds until the LED starts blinking.
  2. Select Target Slot:
    • Use the rotary knob to choose the target program number in the user bank where you want to store the preset.
  3. Confirm Save:
    • Press the rotary knob once, briefly to confirm and save the preset.

Warning: Saving a preset will overwrite any existing preset stored in the selected program number of the user bank. Ensure you have backed up or no longer need the previous preset before proceeding.

Base Algorithms

The MX Modular FX Module features the following base algorithms, each tailored to provide unique sonic characteristics for creative effects processing:

  1. Reverb:
    • A lush, customizable reverb algorithm with parameters to shape the space, tone, and dynamic behavior. Ideal for creating ambient environments or enhancing the depth of your mix.
  2. Delay + Modulation:
    • Combines rhythmic delay with modulation effects for added movement and texture. Perfect for creating dynamic, swirling echoes or vibrant soundscapes.
  3. Delay + Reverb:
    • Merges rhythmic delay with reverb to produce rich, layered effects. Excellent for adding rhythmic complexity and spatial depth simultaneously.

Navigating Parameter Rows with the Shift Button

The FX Module provides three rows of parameters for each algorithm, offering detailed control over effect characteristics. The Shift Button is used to navigate between these rows:

  • Shift Unlit: Default state, controlling Row 1 parameters.
  • Shift Lit (short press): Activates Row 2 parameters, providing additional tonal and dynamic controls.
  • Shift Blinking (long press): Activates Row 3 parameters, enabling advanced customization of the effect.

This intuitive navigation system ensures quick access to all effect parameters, empowering you to fine-tune each algorithm for your specific needs. With these three base algorithms and comprehensive parameter control, the MX Modular FX Module is a powerful tool for both studio and live sound applications.

Stereo AUX and BUS

The Master Section of the MX Modular offers robust routing options with 2 stereo AUX sends and 2 stereo BUS routings, each designed to provide maximum flexibility for creative and performance needs.

Stereo AUXes

The Stereo AUXes are by default routed to both the internal FX and the backpanel

Each of the stereo AUX sends is equipped with:

  • Send knob: Adjusts the level of the signal sent from the AUX 1/2 to internal FX 1/2 and external devices like effects units or additional mixing gear.
  • Return knob: Controls the level of the signal being returned from the internal FX 1/2 and an external device back into the console.

On the back panel, you'll find stereo balanced inputs and outputs dedicated to each AUX send and return. This ensures high-quality, noise-free connections with external gear.

Use the left return input only for mono devices.

Stereo BUSses

The 2 stereo busses function similarly to the AUX sends and returns but come with an additional layer of functionality:

  • Send knob: Controls the signal level sent to the stereo bus output.
  • Return knob: Adjusts the signal level returned from external devices or routing paths.
  • Insert Button (BUS INS EXT): Activates an additional insert feature, allowing you to seamlessly route the signal through external processors or outboard gear for further signal manipulation.

As with the AUX section, the back panel includes stereo balanced inputs and outputs for each stereo bus, maintaining pristine audio quality across all connections.

Use the left return input only for mono devices.

Key Features Recap

  • 2 Stereo AUX Sends with send and return knobs.
  • 2 Stereo Busses with send and return knobs, plus an Insert Button for external processing.
  • Stereo Balanced Inputs and Outputs on the back panel for all AUX sends and busses.

These features make the MX Modular's master section a versatile hub for integrating outboard effects, additional summing paths, or customized signal routing in both studio and live settings.

Expanded Explanation: AUX Send and Return Functionality

The AUX section of the MX Modular is designed to provide maximum flexibility, allowing seamless integration of external FX and the built-in FX engine. Here’s how the routing and mixing options work:

AUX Send Routing

  • The AUX Send Signal is always routed to:
    1. The external AUX outputs on the back panel, allowing you to connect outboard effects units.
    2. The built-in FX engine:
      • AUX 1 routes to the upper FX Slot (FX 1).
      • AUX 2 routes to the lower FX Slot (FX 2).

This dual routing ensures that both external and internal FX paths are active simultaneously, offering you the ability to blend effects from both sources.

AUX Return Routing

  • The Return Signal comes from:
    1. The external FX unit connected to the AUX Return Inputs on the back panel.
    2. The processed signal from the built-in FX engine.

Mixing Internal and External FX

You can mix the internal and external FX signals to create unique and layered soundscapes. To adjust the balance:

  • Use the output volume control on the external FX unit to set the desired level of its return signal so that it's in balance with the builtin FX.

Disabling Internal FX

If you prefer to use only external FX:

  • Set the internal FX Program to "00" on either FX Slot (FX 1 or FX 2). This effectively disables the internal FX processing while keeping the external FX routing intact.

Key Features Recap:

  • AUX Sends always route to both the external AUX outputs and the built-in FX engine.
  • AUX Returns combine external and internal FX signals for creative mixing.
  • Adjust the balance between internal and external FX using the external FX output volume.
  • Internal FX can be disabled by selecting Program "00" on each FX Slot.

This integrated design allows you to craft your sound with precision, blending internal and external FX for studio-grade mixing or live performance versatility.
